## 1. أدوار المستخدمين (User Roles)

### 1.1 مدير النظام (Super Admin)
```
الصلاحيات: كاملة - كل شيء في النظام
المسؤوليات:
  - إدارة المستخدمين والأدوار
  - إعدادات النظام الكاملة
  - الفروع والأقسام والهيكل التنظيمي
  - النسخ الاحتياطي والاستعادة
  - سجل النشاطات (Audit Log)

ما يراه في الواجهة:
  ✅ لوحة التحكم (كاملة)
  ✅ إدارة الموظفين (كاملة)
  ✅ الحضور والانصراف (كامل)
  ✅ الإجازات (كاملة)
  ✅ الرواتب (كاملة)
  ✅ التوظيف (كامل)
  ✅ الأداء (كامل)
  ✅ التدريب (كامل)
  ✅ التقارير (كاملة)
  ✅ الإعدادات (كاملة)
```

### 1.2 مدير الموارد البشرية (HR Manager)
```
الصلاحيات: إدارة كل ما يخص الموظفين
المسؤوليات:
  - إضافة وتعديل بيانات الموظفين
  - إدارة العقود والمستندات
  - معالجة الرواتب
  - إدارة التوظيف
  - اعتماد الإجازات النهائي
  - إدارة التدريب
  - إعداد التقارير

ما يراه في الواجهة:
  ✅ لوحة التحكم (كاملة)
  ✅ إدارة الموظفين (إضافة، تعديل، أرشفة)
  ✅ الحضور والانصراف (عرض، تعديل، إدخال يدوي)
  ✅ الإجازات (موافقة، رفض، إدارة الأرصدة)
  ✅ الرواتب (حساب، اعتماد، تصدير)
  ✅ التوظيف (كامل)
  ✅ الأداء (إنشاء تقييمات، اعتماد)
  ✅ التدريب (إنشاء دورات، تسجيل موظفين)
  ✅ التقارير (كاملة)
  ❌ الإعدادات (قراءة فقط - لا تعديل على النظام)
```

### 1.3 المدير المباشر (Manager)
```
الصلاحيات: إدارة فريقه فقط
المسؤوليات:
  - موافقة/رفض إجازات فريقه
  - تقييم أداء موظفيه
  - متابعة حضور فريقه
  - مراجعة العمل الإضافي لفريقه

ما يراه في الواجهة:
  ✅ لوحة التحكم (إحصائيات فريقه فقط)
  ✅ إدارة الموظفين (عرض فريقه فقط)
  ✅ الحضور (عرض فريقه)
  ✅ الإجازات (موافقة/رفض لفريقه + طلب لنفسه)
  ❌ الرواتب (قسيمة راتبه فقط)
  ❌ التوظيف (عرض فقط)
  ✅ الأداء (تقييم فريقه + عرض تقييمه)
  ✅ التدريب (دوراته + ترشيح فريقه)
  ❌ التقارير (تقارير فريقه فقط)
  ❌ الإعدادات (لا وصول)
```

### 1.4 الموظف (Employee)
```
الصلاحيات: بياناته الشخصية فقط
المسؤوليات:
  - تسجيل حضور وانصراف
  - تقديم طلبات إجازة
  - الاطلاع على قسيمة راتبه
  - إتمام دوراته التدريبية

ما يراه في الواجهة:
  ✅ لوحة التحكم (ملخص بياناته فقط)
  ✅ بياناته الشخصية (عرض فقط)
  ✅ الحضور (تسجيل حضور/انصراف + عرض سجله)
  ✅ الإجازات (تقديم طلب + عرض رصيده)
  ✅ الرواتب (قسيمة راتبه فقط)
  ❌ التوظيف (لا وصول)
  ✅ الأداء (عرض تقييمه + أهدافه)
  ✅ التدريب (دوراته + التسجيل في دورات)
  ❌ التقارير (لا وصول)
  ❌ الإعدادات (لا وصول)
```

## 2. سير العمل الرئيسية (Main Workflows)

### 2.1 دورة حياة الموظف الكاملة (Employee Lifecycle)

```
┌─────────────────────────────────────────────────────────────────────┐
│                     دورة حياة الموظف                                 │
│                                                                      │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐      │
│  │  توظيف   │───▸│ تعيين    │───▸│  عمل     │───▸│  خروج   │      │
│  │Recruiting│    │Onboarding│    │  Active   │    │Offboarding│     │
│  └────┬─────┘    └────┬─────┘    └────┬─────┘    └────┬─────┘      │
│       │               │               │               │             │
│  ┌────┴────┐    ┌─────┴─────┐   ┌────┴────────┐  ┌───┴──────┐     │
│  │نشر وظيفة│    │إنشاء ملف │   │حضور/إجازات │  │تسوية    │     │
│  │استقبال  │    │الموظف    │   │رواتب       │  │نهاية   │     │
│  │مقابلات  │    │فتح حساب  │   │تقييم/تدريب │  │خدمة    │     │
│  │عرض عمل  │    │عقد عمل   │   │ترقيات      │  │أرشفة   │     │
│  └─────────┘    │تدريب بدء │   └────────────┘  └──────────┘     │
│                  └───────────┘                                      │
└─────────────────────────────────────────────────────────────────────┘
```

#### المرحلة 1: التوظيف
```
1. مدير القسم يطلب موظف جديد
       ↓
2. HR ينشر الوظيفة الشاغرة
       ↓
3. استقبال طلبات المتقدمين
       ↓
4. فرز أولي بواسطة HR
       ↓
5. مقابلة أولى (HR)
       ↓
6. مقابلة ثانية (المدير الفني)
       ↓
7. مقابلة نهائية (المدير التنفيذي) [حسب المستوى]
       ↓
8. إرسال عرض العمل
       ↓
9. قبول المتقدم
       ↓
10. تحويل المتقدم إلى موظف
```

#### المرحلة 2: التعيين (Onboarding)
```
1. إنشاء ملف الموظف
   ├── البيانات الشخصية
   ├── البيانات الوظيفية
   └── البيانات المالية (بنك، IBAN)
       ↓
2. إنشاء العقد
   ├── نوع العقد (محدد/غير محدد)
   ├── الراتب والبدلات
   └── تاريخ البدء والانتهاء
       ↓
3. رفع المستندات المطلوبة
   ├── صورة الهوية/الإقامة
   ├── شهادات الخبرة
   ├── الشهادات الأكاديمية
   └── صورة شخصية
       ↓
4. التسجيل في التأمينات (GOSI)
       ↓
5. إنشاء حساب المستخدم (اسم مستخدم + كلمة مرور)
       ↓
6. تحديد المدير المباشر والقسم والفريق
       ↓
7. تسجيل في الدورات التدريبية الإلزامية
       ↓
8. تحديد جدول العمل والوردية
```

#### المرحلة 3: العمل اليومي
```
يومياً:
  ├── تسجيل حضور (بصمة/وجه/GPS)
  ├── تسجيل انصراف
  └── احتساب ساعات العمل

شهرياً:
  ├── حساب الراتب
  ├── خصم التأخيرات والغياب
  ├── إضافة العمل الإضافي
  └── صرف الراتب

دورياً:
  ├── تقييم الأداء (سنوي/نصف سنوي)
  ├── مراجعة العقد (عند الانتهاء)
  ├── تجديد المستندات
  └── دورات تدريبية
```

#### المرحلة 4: الخروج (Offboarding)
```
1. طلب استقالة أو قرار إنهاء خدمة
       ↓
2. بدء فترة الإشعار (حسب النظام)
       ↓
3. حساب التسوية المالية
   ├── رصيد الإجازات غير المستخدمة
   ├── مكافأة نهاية الخدمة
   ├── خصم السلف المتبقية
   └── أي مستحقات أخرى
       ↓
4. تسليم العهد (أجهزة، بطاقات، مفاتيح)
       ↓
5. إلغاء التسجيل من التأمينات
       ↓
6. إصدار شهادة الخبرة
       ↓
7. تعطيل حساب المستخدم
       ↓
8. أرشفة الملف (مع سبب الخروج)
```
