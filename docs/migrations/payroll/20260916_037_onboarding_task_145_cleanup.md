## لماذا ليس ملف `.sql` أو `.cjs`

`api/scripts/db-migrate.cjs` يمنع حذف صفوف الشركة بحارسين، والملف يُرفض قبل أي اتصال وفي كل تشغيل بعده:

1. **الفحص النصي** (`FORBIDDEN`): `DELETE` ممنوع لأي جدول دائم — «DELETE ممنوع (لا حذف لصفوف الشركة؛ عطّل الصف أو غيّر حالته)». سكربت `.cjs` يُفحص بالقواعد نفسها (`repository.delete/remove`، `QueryBuilder.delete()`، وأي نص يشبه SQL).
2. **الفحص الفعلي** قبل الالتزام: كل صف قائم يجب أن يبقى بمفتاحه الأساسي؛ اختفاء الصف يُرجِع الملف كله.

ولو أُضيف الملف لبقي مرفوضًا إلى الأبد، فيوقف `plan`/`apply` لبقية ترحيلات الموجة. لم يُضعَّف أي حارس، ولم تُعدَّل قواعد المُرحّل.

## ما نُفّذ فعلًا (بيان واحد بحارس مركّب)

```sql
DELETE FROM dbo.onboarding_tasks
WHERE id = 145 AND employeeId = 204 AND templateItemId IS NULL;
-- صف واحد متأثر
```

الحارس المركّب (المعرّف + الموظف + كون المهمة يدوية) يمنع إصابة أي صف آخر لو أُعيد تنفيذه على قاعدة مختلفة.
