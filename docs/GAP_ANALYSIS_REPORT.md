### 3.3 حساب التأخير بناءً على الجدول الأسبوعي

#### المنطق (Logic):
```javascript
// Pseudocode لحساب التأخير
function calculateLateness(employee_id, attendance_date, check_in_time) {
    // 1. جلب الجدول الأسبوعي للموظف
    const schedule = getEmployeeSchedule(employee_id, attendance_date);
    
    // 2. تحديد أي أسبوع من الشهر
    const weekNumber = getWeekOfMonth(attendance_date); // 1, 2, 3, أو 4
    
    // 3. جلب الوردية المطبقة لهذا الأسبوع
    const shift = getShiftForWeek(schedule.id, weekNumber, attendance_date.dayOfWeek);
    
    // 4. حساب التأخير
    if (check_in_time > shift.start_time) {
        const lateness = check_in_time - shift.start_time;
        return {
            is_late: true,
            late_minutes: lateness,
            expected_time: shift.start_time,
            actual_time: check_in_time
        };
    }
    
    return { is_late: false, late_minutes: 0 };
}
```

#### ج) منطق الخصم:
```javascript
// مثال: إذن ساعتين، الموظف تأخر 3 ساعات
function calculatePermissionDeduction(permission) {
    const type = permission.permission_type;
    const requestedMinutes = permission.requested_minutes; // 120
    const actualMinutes = permission.actual_minutes;       // 180
    const excessMinutes = actualMinutes - requestedMinutes; // 60
    
    if (type.deduction_type === 'none') {
        return 0;
    }
    
    if (type.deduction_type === 'full') {
        return actualMinutes * type.deduction_rate;
    }
    
    if (type.deduction_type === 'after_threshold') {
        // يخصم فقط ما زاد عن المسموح
        if (actualMinutes > type.deduction_threshold_minutes) {
            return (actualMinutes - type.deduction_threshold_minutes) * type.deduction_rate;
        }
        return 0;
    }
    
    if (type.deduction_type === 'partial') {
        // يخصم الزيادة فقط
        return excessMinutes * type.deduction_rate;
    }
}

// في المثال أعلاه:
// إذا كان deduction_type = 'partial' و deduction_rate = 1.0
// الخصم = 60 دقيقة (ساعة واحدة)
```

## 6. الرواتب

### 6.1 المشاكل الحالية

#### أ) دورة الرواتب غير موجودة
#### ب) خيار إزالة الخصم غير موجود

### 6.2 التحسينات المطلوبة

#### أ) إعدادات دورة الرواتب:
```
الجدول: payroll_settings (إعدادات الرواتب)
├── id (PK)
├── company_id (FK)
├── payroll_frequency (monthly, biweekly, weekly)
├── payroll_cycle_type (calendar_month, custom)
│   ├── calendar_month: من 1 إلى آخر الشهر
│   └── custom: تاريخ مخصص
├── cycle_start_day (يوم بداية الدورة - مثال: 23)
├── cycle_end_day (يوم نهاية الدورة - مثال: 22)
├── payment_day (يوم صرف الراتب - مثال: 27)
├── include_weekends_in_calculation (boolean)
├── auto_generate_payroll (boolean)
└── approval_workflow_id (FK)
```

**مثال:**
```
إعدادات الشركة:
├── نوع الدورة: مخصص
├── بداية الدورة: يوم 23 من كل شهر
├── نهاية الدورة: يوم 22 من الشهر التالي
└── يوم الصرف: يوم 27

دورة راتب يونيو 2026:
├── الفترة: 23 مايو 2026 → 22 يونيو 2026
├── يوم الصرف: 27 يونيو 2026
└── يحتسب فيها: الحضور، التأخيرات، الإجازات، الخصومات، البدلات

```
الجدول: approval_workflows (دورات الاعتمادات)

│                  asset, loan, expense, document, custom)

├── is_active

| العنصر | دورة الاعتماد المقترحة |

| إرجاع عهدة | موظف → مدير مباشر → HR |
| طلب سلفة | موظف → مدير مباشر → HR → المالية |
| طلب استقالة | موظف → مدير مباشر → HR → الإدارة العليا |
| تصفية مستحقات | HR → المالية → الإدارة العليا |
| إزالة خصم | مدير مباشر → HR |
| تعديل راتب | HR → المالية → CEO |
