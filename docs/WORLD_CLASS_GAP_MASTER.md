# HR System – World-Class Gap Master List
# الجرد الشامل للفجوات — مقارنة بنظام موارد بشرية عالمي

**التاريخ:** 2026-07-07
**الطريقة:** فحص عميق للنظام بالكامل (كل الموديولات + التوثيق) عبر 7 محاور تدقيق، ومقارنته بمعايير HRIS عالمي (Workday / SuccessFactors / BambooHR / Oracle HCM) + الامتثال السعودي.
**الخلاصة الجوهرية:** النظام **نموذج واجهة (UI Prototype) عالي الجودة بصرياً** يغطّي *عرض* معظم الشاشات — لكن **صفر منطق خلفي**: لا حفظ، لا سير عمل فعلي، لا ترابط بين الموديولات، لا تكاملات. المطلوب لبنائه كنظام عالمي مُقسَّم أدناه.

## 1. الأساس (Foundation) — يجب أولاً

1. **Backend + قاعدة بيانات + API فعلي** — لا يوجد أي منها (كل شيء hardcoded).
2. **طبقة بيانات موحّدة (Single Source of Truth)** — البيانات مكرّرة يدوياً في كل صفحة.
3. **Multi-Branch RBAC:** ربط المستخدم بالفرع (`user_branches`), نطاق صلاحية `branch`, علم super-admin, فرض عزل البيانات (RLS)، فلتر فرع موحّد، Branch Switcher.
4. **المصادقة:** MFA/OTP فعلي, SSO/SAML/AD, **تكامل نفاذ (Nafath)** الحكومي, إدارة جلسات.
5. **i18n فعلي:** كل النصوص عربية مثبّتة — لا ملفات ترجمة ولا إنجليزية منفّذة.
6. **تقويم هجري فعلي** (احتساب لا مجرد خيار عرض) + custom fields + feature flags + backup/restore.

---

## 2. محرّك الطلبات والاعتمادات + الخدمة الذاتية (العمود الفقري)

7. **نموذج طلب مركزي (Generic Request)** بحالة موحّدة وسجل تدقيق.
8. **محرّك تنفيذ (Runtime):** خطوة حالية، سجل موافقات، تفويض/تصعيد فعلي، نِصاب (AND/OR/parallel), إعادة توجيه (rework), سحب الطلب.
9. **توصيل محرّك `settings/approvals` الموجود** بنماذج التقديم (حالياً طلب الإجازة = `console.log`).
10. **استهداف الطلبات (Targeting):** توجيه نوع طلب لموظف/فريق/قسم/فرع/درجة + قواعد أهلية + تمييز عام/مستهدف.
11. **بوابة خدمة ذاتية (ESS):** "طلباتي" + "بياناتي" + "مهامي".
12. **صندوق الموافقات الموحّد (Approvals Inbox)** لكل الأنواع في مكان واحد (بدل widget ثابت).
13. **أنواع طلبات ناقصة (نموذج + مسار + صندوق):** استقالة ذاتية · تغيير بيانات · سلفة · مصاريف · شهادة/تعريف · رحلة عمل · عمل عن بُعد · تغيير وردية · شكوى/تظلّم · تظلّم على خصم · طلب عهدة.

---

## 3. الحضور والورديات

14. **جدول أسبوعي مؤرّخ** (`weekly_schedule_entries`: موظف+تاريخ+وردية) — الحالي بأسماء أيام مجردة بلا تواريخ.
15. **محرّك حساب التأخير/الخروج المبكر** يقارن البصمة بوردية اليوم مع فترة السماح.
16. **فصل "أيام العمل" عن "ساعات الوردية"** + قواعد محسوبة (آخر سبت/رمضان) + ربط بالعطل.
17. **التقرير الشهري اليومي** لكل موظف (ماضٍ فعلي / قادم "لم يحن") بدل الإجماليات فقط.
18. **الأوفرتايم:** عتبة توجيه للاعتماد + دورة متعددة المستويات + عدم الاحتساب في الراتب إلا بعد الاعتماد + احتساب تلقائي من البصمة.
19. **الأذونات:** إدارة أنواع + إعدادات لكل نوع + حد شهري + **منطق خصم فرق تجاوز مدة الإذن** + ربط بإلغاء تأخير اليوم.
20. **تسجيل حضور جغرافي (GPS/geofencing) + selfie** فعلي + تكامل أجهزة البصمة الحقيقي.

---

## 4. الرواتب والتعويضات والمزايا

21. **إعداد دورة رواتب مرنة** (anchor day مثل 23→22, نصف شهرية) + دفعات خارج الدورة.
22. **كيان مسير رواتب** بدورة حالة + **اعتماد متعدد المستويات فعلي** + **مسير لكل فرع** + تسوية/مطابقة (reconciliation).
23. **خصومات ديناميكية** قابلة للإلغاء/التعليق قبل القفل مع سبب وسجل تدقيق.
24. **هيكل درجات كامل:** steps/midpoint/compa-ratio + **دورة مراجعة/زيادة الرواتب** + سجل رواتب تاريخي.
25. **CTC الكامل** (أساسي+بدلات+حصة GOSI+مخصص نهاية خدمة+تأمين+تذاكر) + **دفع بأثر رجعي (retro)** + تعدد عملات + تحليل عدالة الأجور.
26. **المزايا:** وحدة تأمين طبي (وثيقة/فئة/مزوّد/ربط CCHI) + **سجل معالين** + تسجيل ذاتي + **تذاكر طيران سنوية** (استحقاق/تراكم) + دفتر مخصصات نهاية الخدمة.
27. **توليد ملف WPS/بنكي فعلي** + توزيع قسائم + **تكامل محاسبي/GL** (قيود/مراكز تكلفة).

---

## 5. الإجازات

28. **رصيد افتتاحي/مُرحّل يُدخل يدوياً** عند إضافة موظف قائم + **تاريخ انتهاء** له (نهاية سنة/تاريخ محدد/بلا).
29. **فصل طبقات الرصيد** (قديم مُرحّل × جديد متراكم من الالتحاق) + **محرّك تراكم فعلي** + مهمة ترحيل سنوي.
30. **امتثال سعودي للإجازات:** زيادة تلقائية لـ30 يوماً بعد 5 سنوات + تدرّج أجر الإجازة المرضية (م.117).

---

## 6. التوظيف والتهيئة

31. **دورة اعتماد طلب التوظيف (Requisition)** مربوطة بالميزانية والهيكل + **اعتماد العرض** + توقيع إلكتروني.
32. **بوابة توظيف خارجية (Careers Portal)** + تقديم ذاتي + تحليل سير ذاتية + مصادر التوظيف/الإحالات.
33. **بطاقات تقييم المقابلات (Scorecards)** بالكفاءات + توصية hire/no-hire.
34. **تحويل المتقدم → موظف** تلقائياً + مجمّع مواهب (Talent Pool) + تحليلات توظيف (time/cost-to-hire).
35. **وحدة Onboarding كاملة (غائبة):** checklists قبل/بعد المباشرة + إسناد مهام (HR/IT/مدير) + جمع مستندات + تجهيز/تزويد + مرشد + تتبّع فترة التجربة وقرار التثبيت.

---

## 7. الأداء والتطوير والمسار المهني

36. **الأداء:** تدرّج أهداف/OKR هرمي + تغذية راجعة مستمرة/1-on-1 + **360 درجة** + تقييم ذاتي + **معايرة (calibration)** + إطار كفاءات + **PIP** + ربط بالتعويض/الترقية + اعتماد متعدد المراحل.
37. **التدريب:** **LMS فعلي** (محتوى/فيديو/SCORM/تتبّع) + مسارات تعلّم حقيقية + شهادات بتنبيهات تجديد + تدريب إلزامي بتعيين آلي + **مصفوفة مهارات** + ميزانية + طلبات تدريب خارجي.
38. **المسار المهني والإحلال (غائب كلياً):** 9-box + تخطيط إحلال (خلفاء/جاهزية/flight-risk) + مسارات مهنية + جرد مهارات مؤسسي + حراك داخلي.

---

## 8. العهد ودورة الخروج (Custody & Offboarding)

39. **نظام العهد كامل (غائب):** أنواع عهد في الإعدادات + سجل تخصيص للموظف (checkbox+تاريخ) + دورة اعتماد تسليم + **إرجاع/تحرير** مستقل + ربط تلف/فقد بالخصومات والتصفية.
40. **تدفق الاستقالة الذاتي** → اعتماد → **فترة إشعار** → Offboarding Checklist → قفل العقد → **تصفية تلقائية**.
41. **تصفية المستحقات:** دورة اعتماد حقيقية (HR→مالي→مدير عام) + **إشعار/إقرار الموظف (مخالصة)** + جدول قاعدة بيانات + مصدر حساب موحّد + **EOSB مطابق للنظام** (الأجر الكامل لا الأساسي فقط + تدرّج م.85 للاستقالة).
42. **الأرشفة التلقائية** بعد التصفية + تعطيل الحساب + **شهادة خبرة/إخلاء طرف** + إعادة توظيف (Rehire).

---

## 9. بيانات الموظف والحوكمة

43. **سجل التاريخ الوظيفي (Job History)** لكل موظف (مسمى/قسم/راتب/مدير) مؤرّخ بسبب + timeline.
44. **سجل التدقيق (Audit Trail UI)** — الجدول موثّق لكن **لا واجهة** لعرض "من فعل ماذا ومتى" + field-level history.
45. **سجل معالين + جهات اتصال طوارئ** (تُدخل ولا تُعرض/تُدار) + custom fields.
46. **إدارة المناصب (Position Management)** منفصلة عن الأشخاص + تقارير مصفوفية (matrix).
47. **حوكمة/خصوصية (PDPL):** field-level visibility/masking + consent + حق النسيان/تصدير بيانات + تصنيف بيانات حساسة.

---

## 10. المنصة (Reporting / Notifications / Docs / Integrations / Calendar)

48. **BI فعلي:** تصدير Excel/PDF حقيقي + drill-down/pivot + **لوحات حسب الدور** + KPIs متقدمة (turnover/absenteeism/time-to-hire/سعودة) + تقارير مجدولة + تنبؤية.
49. **إدارة مستندات:** توقيع إلكتروني + version control + رفع ذاتي/تخزين فعلي + توليد مجمّع + retention policy.
50. **إشعارات:** قنوات فعلية (بريد/SMS/**WhatsApp**/Push) + **real-time (WebSocket)** + قوالب قابلة للتحرير + تصعيد + ملخصات + تفضيلات لكل مستخدم.
51. **التكاملات الحكومية السعودية (حرجة):** WPS/SIF + **مدد (Mudad)** + **قوى (Qiwa)** + **GOSI API** + **أبشر/مقيم (Muqeem)** + نفاذ.
52. **تكاملات عامة:** REST API + webhooks + ERP/محاسبة + استيراد/تصدير مجمّع + أدوات ترحيل بيانات.
53. **التقويم:** مزامنة Google/Outlook (ICS/CalDAV) + هجري فعلي + دعوات/RSVP + حجز موارد.
54. **الموبايل:** تطبيق/PWA + تصميم متجاوب فعلي (النظام حالياً غير متجاوب: تخطيطات ثابتة) + موافقات جوال + إشعارات دفع.

## 11. الامتثال السعودي (مجمّع — حرج للسوق)

55. **تتبّع الإقامة/التأشيرة:** رقم إقامة منفصل + **تاريخ انتهاء الإقامة/التأشيرة/تصريح العمل** + تنبيهات + بيانات الكفالة.
56. **النطاقات/السعودة:** لوحة نسبة التوطين (بلاتيني/أخضر/أصفر/أحمر) + احتساب سعوديين/إجمالي.
57. **GOSI مطابق:** حد الأجر الخاضع (45,000) + فرع الأخطار + **جدول قانون التأمينات الجديد 2025** المتدرّج.
58. **عقود عربية بصيغة قوى/الوزارة** (بنود المادة، محدد/غير محدد، رقم توثيق) + ثنائية اللغة.
59. **رمضان:** فرض تلقائي لساعات مخفّضة + **الأوفرتايم 150% (م.107)** كحد افتراضي.

## 13. الأولويات المقترحة (بناء الفرونت)

**دفعة 1 — الأساس:** Multi-Branch RBAC (شكل الفلاتر/الفرع) + مركز الطلبات + "طلباتي" + صندوق الموافقات الموحّد.
**دفعة 2 — الخروج:** استقالة ذاتية → فترة إشعار → Offboarding → تصفية بدورة + مخالصة → أرشفة + شهادة.
**دفعة 3 — العهد.**
**دفعة 4 — الحضور:** جدول مؤرّخ + عرض التأخير + تقرير شهري يومي.
**دفعة 5 — التغييرات الوظيفية والانضباط:** نقل/ترقية/تعديل راتب + سجل تاريخي + إنذارات/تظلّمات.
**دفعة 6 — العمق الوظيفي:** Onboarding · 360/معايرة · مصفوفة مهارات · إحلال/9-box.
**دفعة 7 — الامتثال السعودي:** إقامة/نطاقات + EOSB مطابق + شاشات WPS/Qiwa/Mudad.
**دفعة 8 — المنصة:** BI + توقيع إلكتروني + قنوات إشعار + Audit UI + لوحات حسب الدور + الموبايل.
